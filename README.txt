PUBBLICAZIONE GRATUITA CON GITHUB PAGES
1. Crea un account GitHub se non ne hai uno.
2. Crea un nuovo repository, ad esempio zio-fester.
3. Carica tutti i file contenuti in questo ZIP.
4. Vai in Settings > Pages.
5. In Build and deployment scegli Deploy from a branch.
6. Seleziona branch main e cartella /(root), poi Save.
7. GitHub ti fornirà un indirizzo pubblico.
